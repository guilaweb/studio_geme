# PROFUNDIDADE - Web Client (Frontend)

Aplicação web empresarial desenvolvida com Next.js 15, TypeScript e Tailwind CSS.

## Funcionalidades Principais
1. Autenticação Segura e Gestão de Sessão JWT
2. Selector de Organização / Multi-Tenancy estrito
3. Dashboard Operacional de Casos, Investigação e Evidências
4. Gestão de Entidades (Pessoas, Empresas, Veículos, Contas)
5. Visualizador de Grafo de Vínculos e Relacionamentos
6. Aquisição e Cadeia de Custódia de Evidências com Hash Criptográfico SHA-256
7. Sistema de Inteligência (SI) com Validação Humana Obrigatória (Human-in-the-Loop)
8. Emissão e Selagem Criptográfica de Relatórios e Dossiers Operacionais
9. Trilha de Auditoria e Conformidade Legal
