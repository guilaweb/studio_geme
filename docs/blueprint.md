# **App Name**: Link Oasis

## Core Features:

- Link Submission: Allow users to submit website links with a title and description.
- Categorized Display: Display submitted links in a categorized and searchable format.
- Upvote/Downvote: Enable users to upvote or downvote links to promote quality content.
- AI Summarization: Use a tool to generate a brief AI-powered summary of linked websites using provided or missing descriptions.
- Tagging: Add tags to submitted links.
- Search: Allow users to search using free text.

## Style Guidelines:

- Primary color: Muted teal (#73A893), for a calming, trustworthy feel.
- Background color: Light gray (#F0F2F5) to ensure readability and a clean aesthetic.
- Accent color: Soft yellow (#D4AC0D) to highlight important interactions.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and 'Inter' (sans-serif) for body.
- Use simple, outline-style icons for categories and actions.
- Maintain a clean, card-based layout for easy browsing.
- Use subtle transitions for feedback, such as a color change on upvote.
